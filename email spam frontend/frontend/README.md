# Email Spam Detection – Frontend

Static HTML/CSS/JS, no build step.

1. Start the backend (see backend/README.md) on http://localhost:5000
2. Open `index.html` in a browser (or `python -m http.server 8080` and visit http://localhost:8080)
3. If the backend is hosted elsewhere, edit `API_URL` at the top of `script.js`.
